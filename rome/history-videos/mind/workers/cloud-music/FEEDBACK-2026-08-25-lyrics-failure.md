## Evan's reaction

The draft beginning `We had the north / Wood smoke. Wet grass...` failed.

His critique, in substance:

- It is a **lyrical telling of the story**, not a song.
- It contains too much information.
- It reads like a chant / narrated plot summary.
- There is no meaningful chorus architecture.
- There is no musical/emotional arc that creates anticipation and release.
- The lyric is trying to explain every beat of the film instead of selecting a small number of emotionally reusable ideas.

## Design rule

Do **not** use the lyrics as the screenplay.

The film already carries the story. The song should carry the emotional engine.

A good lyric for this project should:

1. Choose 1–2 core emotional propositions, not 20 plot facts.
2. Build a **real chorus** with a line the listener wants to hear again.
3. Use verses to reveal only enough information to transform the chorus each time it returns.
4. Preserve space for instrumental motifs, humming, call-and-response, and repetition.
5. Prefer image, tension, and memorable phrasing over exposition.
6. Let the arrangement create an arc: restraint → lift → rupture → return/transformation.
7. If spoken-word is used, it must still behave musically: recurring cadence, refrain, compression, and contrast.

## Practical target

For Part 1, the story material is larger than the lyric. The song probably needs only something like:

- Verse: home / two peoples / one intimate image
- Chorus: love/unity in a genuinely repeatable hook
- Verse: wedding warmth
- Chorus: same hook, now more meaningful
- Bridge: raid / rupture, minimal words
- Final chorus: hook transformed by loss / wandering

Alaric, Roman refuge, bread, and later history do **not** all need to appear in this one lyric merely because they are in the story arc.

## Core correction

**Narrative information belongs primarily in the film. Musical lyrics belong to memory, repetition, emotional compression, and release.**
