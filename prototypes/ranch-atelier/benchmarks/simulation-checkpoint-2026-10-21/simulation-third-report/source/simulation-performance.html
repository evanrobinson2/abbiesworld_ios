Population, method & limitations

The x-axis counts actual animal bodies, not buildings or scenery. Each scene also contains 11 human actors: two adult residents, one child and eight visiting farmhands. The ranch generator estimates one carer per six animals, subtracts residents assigned to care, and caps visiting help at eight. This is an existing staffing rule, not a validated capacity target.

The first two curves retain the original paired renderer measurements. The third is a later FPS run with the same saved scenes, pinned modules, daylight, camera, 1× speed, 1280×720 viewport, five-second warmup and 20-second sample. It adds nearby-peer reuse and hidden-pose bookkeeping skips to the optimized renderer. Machine contention and run timing differ, so this is not evidence that the code change alone caused the FPS difference. Raw load averages, frame intervals, simulation progress and hashes are retained.
