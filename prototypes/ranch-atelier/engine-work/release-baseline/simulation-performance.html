How this was measured

X counts actual animal assets. Every ranch also has 11 people: 2 resident adults, 1 child and up to 8 visiting farmhands. They are simulated characters, not CPU workers.

100–395 animals occupy a single ranch tile; 520–1,000 use expanded boards. The dashed link marks that change. This tests rendering and simulation load; crowded layouts are not a claim of healthy ranch capacity.

Cross-runtime movement is not bit-for-bit deterministic. Same-runtime replay passes; a 1,000-animal Chrome/Node check preserved domain state but showed up to 0.61 m of near-contact path divergence.
