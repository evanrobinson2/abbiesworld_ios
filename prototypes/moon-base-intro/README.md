# Moon Base — First Light

Standalone, playable motion-comic prototype for the Moon Base arrival. Serve this folder locally and open `http://127.0.0.1:5212/`. The intro uses a still from the existing World 2 space plate, editable captions, and provisional vector habitat/lander layers. It is not wired into the parked Moon Base product flow and does not replace the chalk blueprint assets.

The three beats are arrival, touchdown, and the habitat lighting up. Use **Replay intro** or **Skip to arrival**. The lander is a whole-image vector silhouette; there is no character or skeletal rig in this prototype. `sequence.yaml` is the compact editable timing/composition spec, and `arrival-final.jpg` is the verified end frame.
