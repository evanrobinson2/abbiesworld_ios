# Future Plans Documentation

This folder contains documents that describe **what could be** - plans, ideas, suggestions, and potential future features for the project.

## Documents

### `DRAWER_MIGRATION_PLAN.md`
Detailed migration plan for converting from two-column layout to full-width carousels with overlay drawer. Status: ✅ Completed (kept for reference).

### `MINIGAME_IDEAS.md`
Creative minigame concepts that utilize user-generated images and characters. Includes implemented games and ideas for future games with complexity ratings and kid appeal scores.

### `MUSIC_COORDINATION_PLAN.md`
Plan for coordinating MusicService with WaypointGameAudioService to prevent audio session conflicts. Describes independent services with lifecycle coordination.

### `MUSIC_PLAYBACK_PLAN.md`
Implementation plan for background music playback system, including architecture, caching strategy, and Settings UI integration.

### `PHASER_MINIGAMES_PORTING_PLAN.md`
Comprehensive plan for porting Phaser minigames to Swift iOS. Includes game inventory, asset organization, porting strategy, and recommended implementation order.

### `VIEW_MODE_PLAN.md`
Implementation plan for view mode selection system, allowing switching between default (3-carousel) and 4-carousel mode with style selection.

### `VOICE_INTEGRATION_SUGGESTIONS.md`
Approximately 20 different opportunities for voice narration, guidance, and audio feedback throughout the app, organized by app section and user flow.
