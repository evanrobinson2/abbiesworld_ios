# Documentation

This folder contains all project documentation organized by category.

## Structure

### 📋 [current-state/](./current-state/)
Documents that describe **what is** - current implementations, completed features, and existing patterns.

### 🔮 [future-plans/](./future-plans/)
Documents that describe **what could be** - plans, ideas, suggestions, and potential future features.

### 🔧 [problem-solving/](./problem-solving/)
Documents that describe **one-time problem solving** or processes - risk analyses, troubleshooting guides, and process documentation used to set the stage for conversations.
