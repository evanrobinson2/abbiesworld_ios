# Backpack tools (AW-STUDY-0046)

Charm reference renders for Meshy: serve `prototypes/ranch-atelier/dist` on :8765 with `charm-ref.html` copied into
it, then `node tools/backpack/charm-refs.mjs`. Writes one 1024 px picture per charm (no chain, cream background) to
`/mnt/project-files/backpack-charms/<name>/pick.png`. These are stand-ins until each charm has a Midjourney pick.
