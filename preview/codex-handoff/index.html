1. Standing rules (Evan's, non-negotiable)

Read CLAUDE.md, INVARIANTS.md, VISION.md, docs/MODELER_VISION.md, docs/design/LIVING_TOY_WORLD.md, docs/MODELER_STATUS.md, docs/architecture/ before building. In short:

Invariant contracts (INVARIANTS.md, enforced by the invariants workflow; a PR that breaks one does not merge)

  • No minigame or feature is live (reachable from abbies.world) without a real scene in the world and a passing headless-Chrome run that plays it end to end. Otherwise it is experimental: opens only with ?exp=<id> (or ?exp=all) or developer mode. Register it in prototypes/ranch-atelier/dist/simulations/game-registry.json (status, scene, test, tour, and needs for experimental). Static check: node tools/game-registry/check.mjs. Run: node tools/game-registry/run-tests.mjs. Switch: simulations/experimental.mjs (live(id), liveGate(gate)).
  • The town HUD starts from simulations/town-hud-boot.mjs by its own <script type="module" src> tag, exactly once, never inline. Merges have dropped that tag twice. After any merge: grep -c town-hud-boot studies/abbietown/index.html (expect 2 in the deployed page). studies/abbietown/index.html is generated from docs/oracle/abbietown/abbietown.template.html via build_page.py; it has drifted from the template, so diff before rebuilding.
  • No MIDI. Sounds only from the catalogue (prototypes/ranch-atelier/dist/sounds/manifest.json, effects via simulations/catalog-sfx.mjs sfx('id')); music only from the music catalogue or composed tracks. No oscillator or noise-buffer synths. tools/audio-check/check.mjs enforces it; tools/audio-check/baseline.json is empty and may only shrink.
  • Voices are ElevenLabs designed voices only, never cloned. No speechSynthesis, no other TTS. Scripted lines are pre-rendered to R2 with the voice-cast workflow (tools/voice-cast/cast.json); unscripted lines stream through api/live-voice.js after wallet().charge. Kid voices are adult actors.
